Datenschutzerklärung

Der Schutz personenbezogener Daten ist uns wichtig. Auf dieser Seite informieren wir über die Verarbeitung personenbezogener Daten im Zusammenhang mit der Website des fiktiven NRP-Roleplay-Projekts.

2. Hosting durch GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. GitHub stellt die technische Infrastruktur für die Veröffentlichung der HTML-, CSS- und Bilddateien bereit.

Beim Aufruf einer GitHub-Pages-Website wird die IP-Adresse der Besucher laut GitHub aus Sicherheitsgründen protokolliert und gespeichert.

Dabei können insbesondere folgende technische Informationen verarbeitet werden:

  • IP-Adresse des aufrufenden Geräts
  • Zeitpunkt des Zugriffs
  • aufgerufene Website beziehungsweise Unterseite
  • technische Verbindungsinformationen

Diese Verarbeitung erfolgt durch den Hostinganbieter. Die Website-Verwaltung führt selbst keine Besucherstatistiken und erstellt keine eigenen Besucherprofile.

Weitere Informationen: GitHub-Datenschutzerklärung .

3. Nutzung der Website

Die Website ist öffentlich und ohne Anmeldung zugänglich. Es werden keine Benutzerkonten, Registrierungen oder öffentlichen Kontakt- und Bewerbungsformulare angeboten.

Besucher können die veröffentlichten Informationen ansehen, ohne sich auf der Website anmelden zu müssen.

Die Website-Verwaltung speichert keine eigenen Besucherprofile und betreibt keine eigenen Analyse- oder Trackingwerkzeuge.

4. Roblox-Nutzernamen und Anzeigenamen

Im Rahmen des fiktiven Roleplay-Projekts können Roblox-@Namen und Roblox-Anzeigenamen von Projektmitgliedern auf der Website veröffentlicht werden.

Da diese Namen echten Roblox-Konten zugeordnet sein können, behandeln wir sie als möglicherweise personenbezogene Daten.

Eine Veröffentlichung erfolgt ausschließlich nach ausdrücklicher Zustimmung der jeweiligen Person. Die Zustimmung wird über eine entsprechende Discord-Nachricht eingeholt.

Regelung zur Veröffentlichung:
  • Ja / Zustimmung: Der Roblox-@Name und der Roblox-Anzeigename dürfen auf der Website veröffentlicht werden.
  • Nein / Ablehnung: Die Roblox-Daten werden nicht veröffentlicht.
  • Keine Abstimmung: Ohne ausdrückliche Zustimmung erfolgt ebenfalls keine Veröffentlichung.
  • Widerruf: Eine erteilte Zustimmung kann jederzeit widerrufen werden. Die betreffenden Angaben werden anschließend von der Website entfernt.

Wenn keine Zustimmung vorliegt, werden die entsprechenden Felder durch Platzhalter dargestellt. Dazu gehören beispielsweise „@///“ und „///“.

Die fiktiven Dienstnamen, Dienstnummern und Dienstgrade werden unabhängig von den Roblox-Nutzernamen innerhalb des Roleplay-Projekts verwendet.

Zweck der Veröffentlichung ist ausschließlich die Darstellung der fiktiven Organisationsstruktur und der jeweiligen Funktionen innerhalb des Roleplays.

Die vorgesehene Rechtsgrundlage für die Veröffentlichung der Roblox-Namen ist die Einwilligung gemäß Artikel 6 Absatz 1 Buchstabe a DSGVO.

5. Discord und externe Verlinkungen

Die Website enthält einen normalen externen Link zum Discord-Server des NRP-Projekts.

Beim bloßen Anzeigen der Website wird durch diesen Link noch keine Verbindung zu Discord hergestellt. Erst beim Anklicken wird der externe Dienst aufgerufen.

Discord wird außerdem zur Einholung und Dokumentation der Zustimmung zur Veröffentlichung von Roblox-Namen verwendet.

Dabei können Informationen wie Discord-Benutzernamen, Reaktionen und die jeweilige Zustimmung innerhalb des Discord-Servers verarbeitet werden.

6. Cookies und externe Inhalte

Nach der derzeit bekannten technischen Gestaltung verwendet die Website keine eigenen Cookies, keine externen Schriftarten und keine eingebetteten Discord-Komponenten.

Als Schriftart wird Arial verwendet.

Die verwendeten Bilder, beispielsweise die Datei „logo.jpg“, werden lokal von der Website geladen. Es wird hierfür keine externe Google-Bildadresse eingebunden.

7. Speicherdauer

Die veröffentlichten Roblox-Namen bleiben nur so lange auf der Website, wie eine entsprechende Zustimmung besteht und die Veröffentlichung für das Roleplay-Projekt vorgesehen ist.

Nach einem Widerruf werden die betreffenden Angaben von der Website entfernt.

Die Dokumentation der erteilten Zustimmungen wird nur so lange aufbewahrt, wie sie für die Nachweisbarkeit der Einwilligung erforderlich ist.

Für technische Zugriffsdaten, die durch GitHub verarbeitet werden, gelten die Speicherregelungen des Hostinganbieters.

Datenschutzanfragen und Widerrufe können bevorzugt über den NRP-Discord-Server oder alternativ über die angegebene E-Mail-Adresse mitgeteilt werden.
